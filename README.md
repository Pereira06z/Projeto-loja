# 🛍️ Minha Loja

Sistema web de gerenciamento de loja virtual, com vitrine de produtos e cadastro de clientes, produtos e vendas. Desenvolvido com PHP e SQLite. 🐘🗄️

## ✨ Funcionalidades

- 🏪 **Vitrine:** exibe os produtos em cartões com imagem, descrição e preço, com campo de busca
- 📊 **Painel resumido:** contadores de clientes, produtos e vendas cadastrados
- 👥 **Clientes:** cadastro com nome, e-mail, telefone e cidade (criar, editar e excluir)
- 📦 **Produtos:** cadastro com imagem, nome, descrição e preço (criar, editar e excluir)
- 🧾 **Vendas:** registro com data, cliente, produto, quantidade e valor total (criar, editar e excluir)
- 🧭 **Navegação** entre as páginas por menu fixo no topo

## 🛠️ Tecnologias

- 🐘 PHP
- 🗄️ SQLite
- 🎨 HTML5 e CSS3
- 🔀 Git e GitHub

## 🎓 Aprendizados

- 🔄 Construção de um CRUD completo com PHP e banco de dados relacional
- 🔗 Relacionamento entre tabelas (vendas ligadas a clientes e produtos)
- 💅 Criação de interface organizada e consistente com CSS
